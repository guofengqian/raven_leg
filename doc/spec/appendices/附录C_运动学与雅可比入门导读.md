## C.1 先建立一幅画面

**结论.** 旋钮 = \(\mathbf{q}\)；问位置 → 正运动学；问速度 → 雅可比。

| 概念 | 输入 | 输出 | 本项目落点 |
|---|---|---|---|
| 正运动学 | 关节构型 \(\mathbf{q}\) | 点的位置 \(\mathbf{p}(\mathbf{q})\) | `forward_kinematics_tip` |
| 雅可比 | 同上构型下的 \(\mathbf{q}\) | 速度映射矩阵 \(J(\mathbf{q})\) | `jacobian_tip` |
| 速度公式 | \(\dot{\mathbf{q}}\) | \(\dot{\mathbf{p}}=J(\mathbf{q})\,\dot{\mathbf{q}}\) | 接触约束、后续动力学 |

**推导.** 把 RAVEN 的腿想成一条可折叠的尺子，固定在机身髋点上，向外伸出四段杆（大腿 → 下肢 → 偏移杆 → 脚趾）。你能拧动的旋钮，就是广义坐标 \(\mathbf{q}\) 里那几个角度和平移量。

* **问位置**：旋钮拧到某组数值时，爪尖在地面坐标系里落在哪里？→ **正运动学**（§1.1.3）。
* **问速度**：旋钮正在怎样转/平移时，爪尖瞬间往哪飞、飞多快？→ **雅可比**（§1.1.4）。

## C.2 正运动学：从「关节角」到「爪尖在哪」

**结论.** 已知关节 → 求末端（本项目主线）；逆运动学本规范 Step 1 **不做**。位置由 \(\alpha_i\) 定向后沿链累加向量得到。

**推导.** **核心想法**：每一段刚杆长度已知，方向由该段的绝对倾角 \(\alpha_i\) 决定；从髋点出发，把各段向量首尾相接，就得到踝、趾、爪尖的世界坐标。

生活类比：你伸出手臂指远处某点——肩、肘、腕的角度定了，指尖位置也就定了；不必再「猜」指尖在哪，只需按关节一层层加向量。

对本模型：

1. 先由 \(q_3,q_4,q_5,\theta_3,q_6\) 叠出 \(\alpha_1\sim\alpha_4\)（§1.1.2）。
2. 再写 \(\mathbf{p}_1\to\mathbf{p}_2\to\mathbf{p}_3\to\mathbf{p}_4\to\mathbf{p}_{\text{tip}}\)（§1.1.3）。
3. 质心公式同理：在每段杆上取「距近端 \(c_i\)」的一点即可（第 3 章 §3.1）。

记住两件事即可入门：

* **正**运动学 = 已知关节 → 求末端（本项目主线）。
* **逆**运动学 = 已知末端想去哪 → 反求关节（本规范 Step 1 **不做**）。

## C.3 雅可比：从「关节怎么动」到「爪尖怎么动」

**结论.** \(\dot{\mathbf{p}}_{\text{tip}}=J_{\text{tip}}(\mathbf{q})\,\dot{\mathbf{q}}\)；加速度还要 \(\dot{J}\dot{\mathbf{q}}\)。接触与动力学都依赖 \(J\)。

**推导.** 位置公式 \(\mathbf{p}_{\text{tip}}(\mathbf{q})\) 对时间求导，得到速度。因为位置只通过 \(\mathbf{q}\) 依赖时间，链式法则自动长成：

$$
\dot{\mathbf{p}}_{\text{tip}} = J_{\text{tip}}(\mathbf{q})\,\dot{\mathbf{q}}
$$

这里的 \(J_{\text{tip}}\) 就是一张 \(2\times 6\) 的表（平面里只有 \(x,y\) 两个速度分量；六个旋钮对应六列）：

* **第** \(j\) **列**：只拧第 \(j\) 个旋钮、转速为 1 时，爪尖的瞬时速度方向与大小。
* **整表作用**：把六个旋钮的转速 \(\dot{\mathbf{q}}\) 线性组合成爪尖速度。

几何直觉（与附录 A 一致）：

* 平移旋钮 \(q_1,q_2\)：整条腿刚性平移，爪尖跟着平移，前两列是单位阵。
* 转动旋钮（俯仰、髋、踝、趾）：爪尖绕该转轴所在铰点做圆周运动，速度垂直于「铰点 → 爪尖」杆臂，其余列可用杆臂转 \(90^\circ\) 得到。

为何后面处处离不开它？

* **接触**：脚不打滑当且仅当接触点速度为 0，即 \(\mathbf{J}_c\dot{\mathbf{q}}=\mathbf{0}\)（§1.2）。
* **动力学 / 控制**：要把任务空间加速度、地面反力映回关节（第 3–4 章），同样要经过雅可比及其转置。

\(\dot{J}\) 是什么？构型在变时，这张速度表本身也在变；加速度里会出现下面两项（§1.1.5）：

$$
J\ddot{\mathbf{q}} + \dot{J}\dot{\mathbf{q}}
$$

入门阶段先接受：速度用 \(J\)，加速度还要 \(\dot{J}\)。

## C.4 建议阅读顺序与易混点

**结论.** 入门路径：§0.2 → §1.1.2 → §1.1.3 → §1.1.4；细节与单测看附录 A。牢记：髋点 ≠ 质心；\(\alpha_i\) 是绝对角；\(J_{\text{toe}}\) 第 6 列恒 0；claw = tip。

**推导 / 展开.** 推荐路径：

1. §0.2 只扫与 \(q_i\)、\(l_i\)、\(\alpha_i\)、\(\mathbf{p}_{\text{tip}}\)、\(J_{\text{tip}}\) 相关的行。
2. §1.1.2：运动链与绝对倾角。
3. §1.1.3：位置累加得趾关节 / 爪尖。
4. §1.1.4：对照成品雅可比（实现时以此为准）。
5. 附录 A：爪尖 / 趾关节线速度中广义坐标的权重 → 雅可比 \(J_{\text{tip}},J_{\text{toe}}\) → 各列几何（杆臂转 \(\pi/2\)）→ 展开与极限检验。

易混点：

* \(O_B\) / \((q_1,q_2)\) 是**髋点**，不是机身质心；质心还要加 \((d_x,d_y)\) 偏移。
* \(\alpha_i\) 是相对**世界水平轴**的绝对倾角；\(q_4,q_5,q_6\) 是相对前一段的关节角。
* \(J_{\text{toe}}\) 与 \(J_{\text{tip}}\)：前者管趾关节位置，第 6 列恒 0（脚趾转不影响趾关节铰点）。
* 论文里的 \(\mathbf{p}_{\text{claw}}\) = 代码 / 本文的 \(\mathbf{p}_{\text{tip}}\)。
