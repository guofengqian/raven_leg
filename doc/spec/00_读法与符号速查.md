# 0. 读法与符号速查

## 本章目标

作为全套动力学规范的前置基础与总索引，为后续第 1 章至第 8 章确立统一的符号约定、数学口径、论文对应关系与单一事实来源映射。具体解决以下 4 个核心问题：

1. **规范阅读与开发推进路径**：明确“先结论、后推导”的编写风格，规划从新手直觉（附录 C/D）到代码实现（Step 1 \(\to\) Step 5）的最佳学习与编码路径（§0.1）。
2. **全局物理量与符号单一事实标准**：建立全机各坐标系、广义坐标、关节角及力学参量的统一符号词典，避免跨章节符号漂移与混淆（§0.2）。
3. **论文原式与规范章节双向映射**：系统化建立原论文 Methods 式 (2)–(23) 到各分章规范的映射索引，确保学术严谨性与对标可追溯性（§0.3）。
4. **建模假设与 YAML 参数键名映射**：明确刚体假设、平面约化与准定常气动边界，并将所有数学符号与配置文件 `config/robot_paras.yaml` 的键名严格绑定，杜绝代码中的硬编码 Magic Numbers（§0.4–§0.5）。

**完成标志**：通读本章后能够无歧义地查阅全文任一物理符号的定义、坐标系约定与 YAML 键名映射。  
**不在本章范围**：具体运动学与动力学公式推导（见第 1–7 章）。

## 0.4 建模假设与适用范围

**结论.** 模型为矢状面 5 刚体 + 理想铰 + 刚性无滑移接触 + 准定常气动；只覆盖蹬地起跳与起飞过渡，不含着陆缓冲与多腿步态。

**推导 / 条目.**

1. **刚体假设**：机身与 4 段腿杆共 5 个刚体；铰接视为理想转动副，无摩擦、无间隙、无柔性。
2. **平面假设**：全部运动限制在矢状面内，\(z\equiv0\)；所有关节转轴平行于 \(Z\)，侧向、滚转与偏航运动不在模型范围内。`plan/milestone.md` 习惯称该平面为 \(x\text{-}z\) 平面，其 \(z\) 指竖直方向，对应本文 \(Y\)。
3. **左右腿合并**：平面模型把左右腿等效为一条腿，质量按 YAML 的 `simulation.links` 简化模型取值。
4. **足地接触**：地面刚性且水平；约束层面按无滑移处理，法向单向 \(F_y\ge0\)，切向静摩擦锥 \(\lvert F_x\rvert\le\mu F_y\) 由 Step 4 事后校验（约束求解本身不显式含摩擦项）。
5. **弹簧与电机**：线性扭转弹簧、无阻尼，踝簧单向；电机视为理想力矩源，仅受转速—力矩线性外特性限制，不含电气动态。
6. **气动**：准定常模型，压心固连机身；升阻力系数与安装角取自论文 / YAML，不做非定常、地面效应与柔性翼建模。
7. **适用范围**：只覆盖蹬地起跳与起飞过渡的矢状面动力学，不包含着陆缓冲、空中机动与多腿步态。
