# 8. 硬件设计验证与里程碑映射

## 本章目标

对应 [paper_spec.md](../paper_spec.md) **阶段目标 5** 与 `plan/milestone.md` **Step 1 → Step 5**：建立全套动力学建模规范到源码实现的落地映射字典，提供贯穿开发全程、不依赖外部黑盒的数学与物理一致性验证清单（V&V），为仿真保真度与实机轨迹落地提供最终守门保障。具体解决以下 3 个核心问题：

1. **规范条款与代码模块双向追踪**：明确第 1 章至第 7 章的数学公式与核心 Python 代码（`src/kinematics.py`, `src/actuators.py`, `src/dynamics.py`, `src/simulator.py`, `main_benchmark.py`）以及对应单元测试脚本的职责与映射关系（§8.1）。
2. **纯数学与物理一致性检验（V&V）体系**：梳理各阶段必须通过的零容差物理自检判据（包括解析雅可比差分自检、惯性矩阵对称正定、科氏力斜对称、无外力总机械能守恒、触地无滑移约束残差及离地力连续性），确保模型在接入实验数据前内生自洽（§8.2）。
3. **验收交付物闭环检验**：指导开发流程严格按照 Step 1 至 Step 5 逐级推进，统一测试输出报告与图表归档规范（§8.1–§8.2）。

**完成标志**：代码仓库具备可一键复现全部里程碑的自动化测试体系（`pytest tests/`），全阶段物理自检清单项 100% 通过且残差低于验收阈值，最终生成 `output/final_report/` 完整分析报告。  
**不在本章范围**：参数数值经验拟合（见 `doc/missing_params_log.md`）、硬件台架实物电气联调。

## 8.2 数学与物理一致性自检清单（V&V）

**结论.** 在进入下一步里程碑或与论文数据对标前，代码实现必须依次通过以下无依赖的数学/物理守恒检验：

| 检验阶段 | 检验项目 | 数学判据 | 捕获的典型错误 |
|---|---|---|---|
| **运动学（Step 1）** | 解析雅可比 vs 中心差分 | \(\left\| J_{\text{ana}}(\mathbf{q}) - J_{\text{fd}}(\mathbf{q}) \right\|_\infty \to 0\) | 三角函数符号、角度累加遗漏 |
| **运动学（Step 1）** | 雅可比时间导数检验 | \(\left\| \dot{J}(\mathbf{q},\dot{\mathbf{q}}) - \frac{J(\mathbf{q}+\epsilon\dot{\mathbf{q}})-J(\mathbf{q}-\epsilon\dot{\mathbf{q}})}{2\epsilon} \right\|_\infty \to 0\) | 链式求导遗漏 \(\dot{\alpha}_i\) 系数 |
| **驱动与势能（Step 2）** | 扭簧力矩与弹性势能一致 | \(\tau_j = -\partial V_{\text{spring}}/\partial q_j\) | 单向扭簧截断方向或正负号反号 |
| **动力学（Step 3）** | 惯性矩阵对称正定性 | \(\mathbf{M}=\mathbf{M}^T\)，且最小特征值 \(\lambda_{\min}(\mathbf{M}) \gt 0\) | 质心雅可比或转动惯量组装错误 |
| **动力学（Step 3）** | 科氏矩阵斜对称性质 | \(\dot{\mathbf{M}}(\mathbf{q},\dot{\mathbf{q}}) - 2\mathbf{C}(\mathbf{q},\dot{\mathbf{q}})\) 为反对称矩阵 | Christoffel 符号指标或系数错误 |
| **动力学（Step 3）** | 保守系统总机械能守恒 | \(\boldsymbol{\tau}=\mathbf{0},\ \mathbf{f}_{\text{aero}}=\mathbf{0}\) 自由演化时 \(E=T+V=\text{const}\) | \(\mathbf{C},\mathbf{g}\) 与 \(T,V\) 不自洽 |
| **混合仿真（Step 4）** | 触地约束漂移检验 | 触地段内 \(\|\mathbf{p}_c(\mathbf{q}(t))-\mathbf{p}_{c,\text{ref}}\|_\infty\) 在容差内 | KKT 约束项符号错误或积分步长过大 |
| **混合仿真（Step 4）** | 离地连续性与单边力检验 | E2 时刻 \(\lvert F_y \rvert \to 0\)，且质心位置/速度无跳变 | 事件过零方向错误或重置误改 \(\mathbf{q},\dot{\mathbf{q}}\) |
| **论文复现（Step 5）** | 起跳性能对标 | 离地速度、离地俯仰角、地面反力峰值与论文曲线一致 | 参数单位换算、双腿等效缩放或气动系数错误 |

### 8.2.1 Step 1 雅可比极限特例验算

对 [第 1 章 §1.2.1](01_浮基运动学.md#121-足端单点运动学位置雅可比与导数) 与 [附录 A](appendices/附录A_雅可比矩阵权重推导.md) 推导的解析雅可比 \(J_{\text{tip}}(\mathbf{q})\)，在以下 4 组极限工况下应与解析心算及 `tests/test_step1.py` 数值差分严格一致：

| 极限工况 | 物理直觉与预期输出 | 校验的雅可比列 |
|---|---|---|
| 仅 \(\dot{q}_1, \dot{q}_2 \neq 0\) | 整机刚体平移：\(\dot{\mathbf{p}}_{\text{tip}} = [\dot{q}_1, \dot{q}_2]^T\) | 第 1–2 列 \(= \mathbf{I}_2\) |
| 仅 \(\dot{q}_6 \neq 0\) | 仅脚趾绕 \(J_4\) 摆动：\(\lVert\dot{\mathbf{p}}_{\text{tip}}\rVert = l_4\lvert\dot{q}_6\rvert\)，垂直于 \(l_4\) | 第 6 列 \(=\) 趾杆臂转 \(90^\circ\) |
| \(\dot{q}_4 = -\dot{q}_3\)，其余为 0 | 机身抬头与髋反向抵消：\(\dot{\alpha}_i \equiv 0 \implies \dot{\mathbf{p}}_{\text{tip}} = \mathbf{0}\) | 第 3、4 列完全相等 |
| 全链水平伸直（\(\alpha_i = 0\)） | 杆臂全沿 \(+X\)，转 \(90^\circ\) 后切向纯竖直：转动列 \(= [0, \sum l_i]^T\) | 第 3–6 列符号与幅值 |
