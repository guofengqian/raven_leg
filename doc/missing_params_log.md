# 论文未公开参数登记表（missing_params_log）

> 用途：按项目铁律，凡是论文正文 / Extended Data Table 1、2 / 图注中**找不到数值**、
> 但动力学方程又必需的参数，都必须登记在这里，标注物理量纲、影响模块、可行域与建议值，
> **经用户确认后才能写入 `config/robot_paras.yaml`，并必须在注释里标注「估算值，非论文原值」。**

## 来源与状态标记

- **论文原值**：论文正文、表格或图注直接给出；记录页码/表图号。
- **由论文数据推导**：由已给参数按明确公式计算；保留公式，不能称为论文直接给值。
- **项目推断/操作性定义**：为模型闭合或验收测量作出的约定；不能冒充物理测量值或论文结论。
- **待确认**：影响当前模块实现的缺参；在用户决定前不得写入参数文件或用于计算。

### 当前实现阻塞概览

| 参数/定义 | 状态 | 受影响步骤 | 当前处理 |
|---|---|---|---|
| 机身质心偏移、杆件质心位置、杆件惯量 | 待确认 | Step 3 | 不构造依赖这些值的数值质量矩阵；可继续做不依赖其数值的文档审查。 |
| 踝/趾自由角 | 待确认 | Step 2–3 | 不以初始关节角自动代替自由角，除非来源确认。 |
| 静摩擦系数及接触点摩擦参数 | 待确认 | Step 4 | 未确认前不能宣称摩擦锥通过。 |
| 弹簧对照功率下降阈值 | 项目验收定义待补 | Step 5 | 未给出比例阈值前只报告结果，不判通过。 |

上述“受影响步骤”描述阻塞范围，不改变里程碑的 Step 顺序或验收门槛。

## 1. 机身质心在本体坐标系中的偏移 (d_x, d_y)

| 项目 | 内容 |
|---|---|
| 符号 | 规范符号 `d_x`, `d_y`；旧 YAML 注释曾写 `d_z` |
| 物理含义 | 机身刚体质心 C 在机身本体矢状面坐标系中的偏移（原点 = 髋关节中心，x_B 指向机头，y_B 指向背侧） |
| 量纲 | m |
| 影响模块 | `src/dynamics.py` 质量矩阵 M(q)、重力项 g(q)；`src/kinematics.py` 质心映射 |
| 论文状态 | **未给出任何数值**。Extended Data Table 2 只有质量和长度；正文 p13-16 只给 M(q) 的符号形式 |

### 候选范围（项目推断，尚未验证）

| 方向 | 约束 | 来源 |
|---|---|---|
| x | `d_x < 0`（质心在髋关节后方） | 用户确认的定性判断 |
| x | `d_x < 0`（候选方向：髋后） | 既有项目笔记对论文 p13 的解释，仍需回看原图/坐标定义核验 |
| x | `d_x > -0.02`（候选） | 论文 p4 仅陈述质心在气动中立点前方；将机翼压心 `P_wx=-0.02 m` 直接等同于中立点位置尚无证据，故此界未证实 |
| y | `d_y > 0`（候选方向：髋上） | 由“髋位于机翼前缘下方附近”的定性描述推断，不是测量值 |
| y | `d_y < 约 0.052`（候选） | 由翼尾压心坐标按面积加权的项目估算；面积加权并不等于严格气动中立点，缺少升力系数与迎角导数等依据 |
| 整体 | 质心投影与趾/后爪支撑区的关系 | 论文图示提供定性线索；目前缺少可复现的图像测量或 CAD 数据，未形成数值约束 |

**项目推断，不是论文直接给出的数值边界**：`d_x ∈ (-0.02, 0) m`，`d_y ∈ (0, 0.052) m`。该窗口由定性文字和压心位置推断，仍需来源核对且不能据此选取单一参数值。

### 历史备选值（**用户已明确暂不采纳；不构成可行域证据**）

| 符号 | 备选值 | 理由 |
|---|---|---|
| `d_x` | -0.010 m | 落在 (-0.02, 0) 窗口中部，髋后 1 cm |
| `d_y` | +0.020 m | 仅是旧备选值；依据依赖未经验证的候选范围 |

> 决定：本阶段不写死数值，`(d_x, d_y)` 保持“待确认”，不进入任何计算。
