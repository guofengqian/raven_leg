# EPFL RAVEN 跳跃起飞纯数学动力学仿真 — 开发里程碑与验收标准

## 指标与测量口径

- **质量口径**：实机称量总质量、论文正文近似质量和仿真简化模型质量分别记录。基准仿真使用 YAML 中标明的仿真模型参数，并在结果中报告实际采用的模型总质量；不得用实机质量替代仿真模型质量。
- **坐标口径**：世界系为 (X)-(Y) 矢状面，(X) 向前、(Y) 向上、(Z) 面外。旧文本的 `z` 或 `Fz` 若明确表示竖直量，按兼容旧命名解释为规范中的 `y` 或 `Fy`；新增内容使用规范命名。
- **工况 A 高度**：腾空段机身质心相对离地时机身质心的最大竖直位移。
- **工况 B 离地高度**：离地事件时机身质心相对仿真初始时刻机身质心的竖直位移。离地水平速度指离地事件时机身质心的世界系水平速度分量；速度向量模长需单独标记为“合速度”。
- **论文口径差异**：如果原论文图表采用的参考点或时间定义与上述项目操作性定义不同，结果需分别列出并说明差异，不得把两者表述为同一测量值。
- **电机峰值功率**：弹簧对照采用相同初态、控制目标和仿真工况；报告腿部电机机械功率绝对值总峰值，并附单电机峰值。通过阈值不得使用“显著低于”等定性词；须在运行对照前给出数值比例阈值和依据。阈值未确定时只报告结果，不判定通过。
- **来源标记**：关键参数或结论标记为“论文原值”“由论文数据推导”“项目操作性定义/算法设置”或“待确认”。推导值需保留公式和来源，不能写成论文直接给出的数值。

## Step 1：几何与运动学模型（正运动学与雅可比矩阵）

- **目标**：建立矢状面（\(x\text{-}y\) 平面）浮基机身与腿部多连杆（髋、膝/踝、脚趾）的正运动学及解析雅可比矩阵。
- **交付物**：
  - [x] 核心代码：`src/kinematics.py`
  - [x] 验收脚本：`tests/test_step1.py`
  - [x] 校验图表：`output/step1_kinematics_check.png`
- **硬性验收标准（Acceptance Criteria）**：
  1. **静态几何解析校验**：输入特殊测试关节角（如腿部完全伸直 \(q=0\)、直角折叠 \(q=\pi/2\)），函数输出的足端坐标 \(\mathbf{p}_{\text{foot}}\) 与手工三角函数解析解的绝对误差 `< 1e-12 m`。
  2. **雅可比数值微分自检**：在 50 组随机关节姿态 \(\mathbf{q}\) 下，对比解析雅可比矩阵 \(J_{\text{leg}}(\mathbf{q})\) 与中心有限差分结果（\(\Delta q = 10^{-7}\)），最大元素绝对误差 `< 1e-6`。
  3. **时间导数 \(\dot{J}\) 校验**：验证雅可比时间导数 \(\dot{J}(\mathbf{q}, \dot{\mathbf{q}})\) 与有限差分近似的一致性，误差 `< 1e-5`。
  4. **可视化几何核验**：生成静态火柴人结构图（`output/step1_kinematics_check.png`），清晰标注质心、各关节旋转中心与脚趾触地点，确认无连杆反向折叠。

  - [ ] 验收脚本：`tests/test_step2.py`
  - [ ] 校验图表：`output/step2_torque_profile.png`
- **硬性验收标准（Acceptance Criteria）**：
  1. **单向储能释放校验**：测试从深蹲压缩（\(q < q_0\)）到完全伸展（\(q > q_0\)）的完整行程，确认弹簧在压缩区间提供正向助推力矩，而在超过自由角度 \(q_0\) 后输出力矩严格为 `0.0 N·m`（无反向拉扯）。

## Step 3：两阶段动力学方程与 KKT 接触求解器

- **目标**：构建浮基多体动力学方程（\(M\ddot{\mathbf{q}} + \mathbf{C} + \mathbf{G} = S^T\boldsymbol{\tau} + J_c^T\mathbf{F}_{\text{GRF}} + \mathbf{F}_{\text{aero}}\)），实现触地阶段 KKT 约束求解与腾空阶段无约束动力学。
- **交付物**：
  - [ ] 核心代码：`src/dynamics.py`
  - [ ] 验收脚本：`tests/test_step3.py`
- **硬性验收标准（Acceptance Criteria）**：
  1. **质量矩阵对称正定校验**：在 100 组随机姿态下，广义质量矩阵 \(M(\mathbf{q})\) 必须满足对称性（`np.linalg.norm(M - M.T) < 1e-12`）与严格正定性（所有特征值 `eigvals > 0`）。
  2. **触地零加速度硬约束校验**：在触地阶段任意输入驱动力矩，求解出加速度 \(\ddot{\mathbf{q}}\) 后，代回足端加速度公式验证 \(J_c \ddot{\mathbf{q}} + \dot{J}_c \dot{\mathbf{q}}\) 的残余误差 `< 1e-10 m/s²`（确保脚趾不穿地、不打滑）。
  3. **无外力总机械能守恒校验（核心物理自检）**：关闭电机、阻尼、推力和气动力。对无冲击、无接触模态切换的保守积分段，检查总机械能（动能 + 重力势能 + 弹性势能）相对初值的最大偏差 `< 0.1%`。若测试跨越离地等事件，分段报告事件前后能量和事件能量跳变量，不能用跨事件差值代替连续段积分误差。理想无冲量离地不应造成机械能跳变；单向弹簧脱嵌段须按其势能本构单独核算和报告。

## Step 4：混合动力状态机与 SciPy 事件触发集成

- **目标**：使用 `scipy.integrate.solve_ivp` 的 `events` 机制串联“下蹲蓄力 → 触地蹬伸 → 离地腾空 → 最高点/平飞过渡”全流程状态机。
- **交付物**：
  - [ ] 核心代码：`src/simulator.py`
  - [ ] 验收脚本：`tests/test_step4.py`
- **硬性验收标准（Acceptance Criteria）**：
  1. **离地瞬间力连续性校验**：事件触发器准确捕获竖直地面反作用力过零时刻；该时刻 `abs(Fy) < 1e-4 N`，且离地前后质心位置与速度连续。
  2. **静摩擦锥防打滑校验**：对触地蹬伸阶段每个接触点、每个时间步分别检查法向反力非负及切向反力满足摩擦上限。全足接触时按趾关节和爪尖分别校验，不能仅以两点合力判定各接触点均不滑。当前无滑移等式约束不含滑移动力学，摩擦超限即该工况验收失败、并标记为当前接触假设不适用；不得报告为有效的无滑移仿真。滑移接触不属于当前交付范围。
  3. **求解器收敛稳定性**：`solve_ivp`（如 `RK45` / `DOP853`）必须在设定时间上限内正常收敛退出，无奇异矩阵警告或步长退化死循环。
